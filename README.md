# Video Subtitle Tool - New UI Branch

This branch contains the modern Electron-based UI for the Video Subtitle Tool.

## 🚀 Quick Start

Navigate to the `VideoSubtitleTool_Electron` folder and follow the setup instructions in its README.md file.

```bash
cd VideoSubtitleTool_Electron
npm install
cd backend
pip install -r requirements.txt
cd ..
npm start
```
