# Video Subtitle Tool - Ultimate Portable

## SUPER SIMPLE SETUP

This is the ultimate portable version that works anywhere!

### STEP 1: Install Prerequisites (One Time Only)

Install these two programs on your computer:

**Node.js** (for the interface)
- Go to: https://nodejs.org
- Download the LTS version
- Install with default settings

**Python** (for AI processing)  
- Go to: https://www.python.org/downloads
- Download Python 3.11 or newer
- IMPORTANT: Check "Add Python to PATH" during installation

### STEP 2: Run the Tool

Double-click: `START_TOOL.bat`

That's it! The first time takes 5-10 minutes to download AI models.
After that, it starts in seconds.

### What This Tool Does

1. **STITCH** - Combines multiple video files
2. **TRANSCRIBE** - Uses AI to generate subtitles  
3. **CORRECT** - Lets you fix the text
4. **BURN** - Creates final video with subtitles

### Professional Features

- High quality video output (lossless)
- Multiple video file support
- Interactive subtitle correction
- Modern, easy-to-use interface
- Works completely offline after setup

### Troubleshooting

**"Node.js not found"**
- Install Node.js from nodejs.org
- Restart computer after installation

**"Python not found"**  
- Install Python from python.org
- Make sure "Add Python to PATH" was checked
- Restart computer after installation

**Slow first run**
- Normal! Downloading 2GB of AI models
- Grab coffee and wait 5-10 minutes

**Antivirus warnings**
- Add this folder to antivirus exclusions
- AI tools sometimes trigger false positives

### System Requirements

- Windows 10/11 (64-bit)
- 4GB RAM minimum (8GB+ recommended)
- 3GB free disk space
- Internet connection (first run only)
