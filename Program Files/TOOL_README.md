# 🎬 Video Subtitle Tool

A simple, user-friendly tool to automatically generate subtitles for your videos using AI.

## 🚀 How to Use

### Option 1: Double-Click to Run
1. **Double-click** `Video Subtitle Tool.bat`
2. The GUI will open automatically

### Option 2: Run Python Directly
1. Run: `python video_subtitle_tool.py`

## ✨ Features

- **🤖 AI-Powered**: Uses OpenAI's Whisper model for accurate transcription
- **🎯 Lossless Quality**: Burns subtitles with perfect video quality preservation
- **📁 Organized Output**: Creates a dedicated workspace folder for your files
- **🎮 Simple Interface**: Just select video, choose AI model, and process
- **🔄 First-Time Setup**: Guides you through workspace creation on first run

## 📋 What You Get

For each video you process, the tool creates:
- **📝 SRT File**: Standard subtitle file that works with any video player
- **🎬 Burned Video**: New video file with subtitles permanently embedded

## 🤖 AI Models Available

- **Tiny**: Fastest, least accurate (39MB)
- **Base**: Balanced speed and accuracy (74MB) 
- **Small**: **RECOMMENDED** - Best balance (244MB)
- **Medium**: Better accuracy, slower (769MB)
- **Large-v3**: Best accuracy, slowest (3GB)

## 📁 How It Works

1. **First Run**: Tool asks you to create a workspace folder
2. **Select Video**: Browse and select your video file
3. **Choose Model**: Pick AI model (Small recommended)
4. **Process**: Tool automatically:
   - Transcribes audio using AI
   - Creates SRT subtitle file
   - Burns subtitles into video with lossless quality
   - Saves both files in your workspace

## 🛠️ Requirements

- Python 3.8+ installed
- FFmpeg installed on your system
- Internet connection (first time only, to download AI models)

## 💡 Tips

- **Small model** is recommended for most users (good balance of speed and accuracy)
- Processing time depends on video length and chosen AI model
- Workspace folder keeps all your subtitle projects organized
- Both SRT and burned video files are saved for maximum compatibility

## 🎯 Perfect For

- Adding subtitles to social media videos
- Making content accessible
- Language learning and transcription
- Creating subtitle files for video players
